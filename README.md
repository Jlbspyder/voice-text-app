# Voice-to-Text AI Assistant

Voice-to-Text AI Assistant is a full-stack application that allows users to ask questions using their voice and receive AI-generated answers as text.

The application records audio directly from the user's microphone, sends the recording to a Node.js/Express backend, and uses Groq's speech-to-text models to transcribe the spoken question. The transcription is then passed to an AI language model, which processes the question and returns a clear text response to the frontend.


The project demonstrates practical integration of browser audio recording, speech-to-text processing, REST APIs, AI language models, asynchronous request handling, and frontend/backend communication.

## Tech Stack

React, TypeScript, Vite, Node.js, Express, Groq API, Whisper speech-to-text, and Tailwind CSS.
